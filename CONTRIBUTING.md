# Contributing

Thank you for considering a contribution.

This project welcomes practical improvements that make cardiac MRI segmentation workflows easier to reproduce.

## Good First Contributions

- Fix unclear documentation.
- Add environment setup notes.
- Add troubleshooting cases.
- Add dataset preparation examples for public datasets.
- Add visualization examples.
- Improve evaluation scripts.

## Medical Data Rules

Do not submit identifiable patient data.

Do not include DICOM files, screenshots, metadata, dates, names, accession numbers, or institution identifiers unless they are from a public dataset that explicitly allows redistribution.

## Pull Request Checklist

- The change has a clear purpose.
- Documentation is updated if behavior changes.
- Commands have been tested when possible.
- Medical privacy rules are respected.
- External projects, papers, and datasets are credited.
